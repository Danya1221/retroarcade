# Retro Arcade

Telegram Mini App: **Neon Serpent / The Lost Signal / Afterlight**.
Общий профиль, серверная проверка игровых действий, PostgreSQL, коллекция и административная панель.

## Запуск на Railway без локального терминала

1. В Railway: **New Project → Deploy from GitHub repo → Danya1221/retroarcade**.
2. В этом же проекте: **New → Database → PostgreSQL**.
3. В сервисе приложения открой **Variables** и добавь:

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` — имя сервиса БД должно совпадать |
| `TELEGRAM_BOT_TOKEN` | Токен нового бота из BotFather |
| `APP_URL` | HTTPS-домен приложения без `/` в конце |
| `BOT_WEBHOOK_SECRET` | Случайная строка из 32–64 букв и цифр |
| `ADMIN_TELEGRAM_IDS` | Твой числовой Telegram ID; несколько ID через запятую |
| `NODE_ENV` | `production` |

4. **Settings → Networking → Generate Domain**. Запиши полученный адрес в `APP_URL`, повтори Deploy.
5. Чтобы однократно подключить бота без терминала: в **Settings → Deploy → Pre-deploy Command** укажи `npm run bot:setup`, затем Deploy. После успешного запуска эту команду можно убрать. Скрипт регистрирует webhook, `/start` и кнопку меню PLAY; не отправляет сообщения пользователям.
6. В BotFather: `/setmenubutton` → выбери бота → HTTPS-ссылка приложения → название PLAY. Скрипт уже делает эквивалентную настройку кнопки. Для запуска через профиль бота настрой Main Mini App в BotFather.
7. Открой `/start` в боте. Административный раздел виден только ID из `ADMIN_TELEGRAM_IDS`.

Миграции выполняются автоматически при старте под advisory lock. `/health` проверяет БД. Docker запускает приложение от непривилегированного пользователя. Не включай `DEV_AUTH` на реальном сервисе: production всё равно игнорирует этот флаг.

## Локальная разработка

Node.js 22+, PostgreSQL 16+.

```sh
npm ci
cp .env.example .env
# Заполни DATABASE_URL. Для локального входа оставь DEV_AUTH=true.
npm run dev
```

Открой `http://localhost:3000`. Локальный аккаунт имеет ID `1`. Для локальной админки добавь `ADMIN_TELEGRAM_IDS=1`. Он никогда не используется для production-входа.

## Игры и управление

- **Snake:** WASD/стрелки, на телефоне свайп или крестовина. Еда, ускорение, редкая еда, множитель, статические и движущиеся препятствия.
- **Maze:** WASD/стрелки/крестовина, `E` или ACT для удара и взаимодействия. Ключ лежит на карте, находится в сундуке или у стража. Дверь выхода требует ключ. Есть семь типов врагов, комнаты с ловушками, лечение, усиление атаки, редкое событие и скрытый символ. Daily Maze использует общий дневной seed UTC.
- **Platformer:** A/D или стрелки, Space / JUMP, E / ACT. Одновременно нажимай движение и прыжок на телефоне. Девять уровней в трёх темах, пропасти, монеты, враги, движущиеся и падающие платформы, контрольная точка, тайник, финальный босс. После финала можно перепроходить уровни.
- `Escape` / кнопка паузы останавливают симуляцию. При уходе в фон игра ставится на паузу.

## Архитектура

```text
web/                 интерфейс, Canvas-рендер, звук, управление
shared/              общие определения, RNG, детерминированная симуляция
games/snake/         Snake
games/maze/          генератор, проверка достижимости, AI, бой
games/platformer/    физика, данные кампании, босс
server/              HTTP API, Telegram auth, экономика, каталог
scripts/             настройка бота, проверки
database/            PostgreSQL, миграции и транзакции
tests/               игровые, API и браузерные тесты
```

Frontend отправляет **входные действия**, а не очки, XP или инвентарь. Backend повторяет те же фиксированные 30 ticks/sec и сам вычисляет результат. Каждая синхронизация проверяет владельца, версию, максимальный размер пакета и соответствие прошедшему серверному времени. Завершение и награда коммитятся в одной транзакции. Повторное завершение возвращает прежний результат. У аккаунта один активный забег.

Сохранение отправляется раз в четыре секунды; после аварийного закрытия восстанавливается **последняя подтверждённая сервером точка**, а не неподтверждённые локальные действия. При потере сети игра останавливается и повторяет тот же пакет. Не более 30 минут на забег. Сессия входа действует 24 часа.

Loot roll выполняется криптографическим RNG сервера. UUID открытия обеспечивает идемпотентность; результат, списание картриджа и компенсация повторов записываются атомарно. Незавершённое открытие восстанавливается после перезагрузки. Реальные деньги и продажа лутбоксов не подключены.

Конфигурация и каталог редактируются в админке как проверяемый JSON. Доступны переключатели игр, XP, pity, веса редкостей, компенсации, новые косметические скины, обычные/скрытые достижения и ежедневные/еженедельные испытания. Новые достижения используют `metric` (`runs`, `snake`, `maze`, `platformer`, `secrets`) и `target`. Встроенные ID удалять нельзя. Админские изменения журналируются. Есть блокировка игрока, изменение XP и исключение результата из рейтинга.

## Проверки

```sh
npm run check
npm test
npx playwright install chromium
node tests/browser.mjs
```

`npm test` без `DATABASE_URL` использует PostgreSQL WASM (PGlite) только для тестов. При заданном `DATABASE_URL` API-тесты используют реальный PostgreSQL — **только отдельную тестовую базу**, поскольку создают тестовые данные. GitHub Actions проверяет PostgreSQL 16 и запускает браузерные проверки.

Проверяется 5 000 seeds, достижимость ключа до двери, детерминированность после сериализации, запрет разворота Snake, прохождение всех девяти уровней, обязательность босса, Telegram HMAC, истечение auth, запрет чужих/закрытых ресурсов, одновременные открытия, повторное завершение и получение наград.
