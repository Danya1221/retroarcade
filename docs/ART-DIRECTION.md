# Главное меню и Snake: графика по референсам

Новая графика создана встроенным OpenAI ImageGen по двум визуальным референсам пользователя. Изображения подключены к живому HTML и игровому canvas; текст, баланс, очки, действия и столкновения не запечены в картинки. Файлы находятся в git, внешний image CDN не нужен.

## Набор ассетов и задания для генерации

- `public/assets/retro-ui/v2/arcade-room.webp`: портретная пиксельная аркадная комната; тёмный свободный центр, игровые автоматы слева, постеры и полки справа, тёплые оранжевые лампы и холодные синие тени. Без UI, текста, кнопок, цифр и логотипа.
- `public/assets/retro-ui/v2/game-covers.webp`: единый атлас 3×2 без промежутков и подписей: зелёная змейка с яблоком; оригинальный герой в красном капюшоне на платформах; красная машина на закате; танк; жёлтый исследователь неонового лабиринта и роботы; контроллер с вопросом. Каждый кадр используется как фон отдельной кнопки.
- `public/assets/snake/forest-arena.webp`: пустое лесное поле, вид строго сверху; тёмная трава в центре, густая рамка из листьев, камней и белых цветов. Без змеи, фруктов, интерфейса и текста. Логическая сетка рисуется canvas поверх картинки.
- `public/assets/snake/sprites.webp`: прозрачный атлас 4×4. Первая строка: голова вправо, прямое тело, поворот слева вниз, хвост с остриём влево. Затем восемь фруктов, три камня и звезда. Зелёная чешуя, светлое брюшко, объёмные пиксельные блики. Координаты источников — `frames.json`; повороты и анимация выполняются в canvas.

Фоны закодированы в WebP quality 89, спрайты — lossless WebP с альфа-каналом. Snake загружает графику при открытии игры. Существующие логотип и иконки сохранены; координаты вывода исключают подписи атласов.

## Сундуки и магазин

ImageGen создал четыре отдельных изображения сундуков на действительно прозрачном фоне. Файлы `public/assets/loot/{arcade,rare,epic,legendary}.webp` сжаты в lossless WebP; каждый предмет целиком помещается в баннер или карточку, без чёрной подложки исходного атласа. Общий запрос: один закрытый оригинальный пиксельный сундук в ракурсе три четверти, по центру квадратной иконки, прозрачный alpha, без текста, рамки и сцены. Варианты: оранжевое дерево с золотом; сапфировый сундук с серебром; аметистовый с магическим свечением; красно-золотой королевский с искрами.

Каталог редкостей и цены находятся в `shared/loot.js`; API отдаёт их вместе с профилем. Покупка списывает монеты и кладёт сундук выбранного типа в инвентарь. Открытие атомарно расходует один предмет и гарантирует объявленную нижнюю границу редкости. Повтор с тем же UUID возвращает прежний результат.

## Поведение

- Пять основных игр и More Games; дополнительные игры и Daily Maze доступны из More Games.
- Баланс, уровень, прогресс XP и рекорды приходят из API. Прогресс учитывает реальную квадратичную шкалу XP и настройку администратора.
- На телефоне боковые разделы размещаются под карточками. Нижняя навигация ведёт в работающие разделы: главная, рейтинг, коллекция, профиль.
- Snake: стрелки/WASD/свайп — поворот; Space/BOOST — ускорение; E/SLOW — замедление на три секунды с 15-секундным восстановлением. Пауза и выход сохраняют забег. Палитры скинов применяются к спрайтам.
- Управление остаётся частью общего детерминированного ядра, сервер повторяет входные действия. Изменение графики не меняет расположение стен и еды.

## Проверка

`npm run check`, `npm test`, `node tests/browser.mjs`.

Браузерные снимки создаются в `test-results/` и публикуются артефактом GitHub Actions: главное меню desktop/mobile, Snake desktop/mobile, админка, платформер, Maze. Они не включены в игровые ассеты. Требуется также ручная проверка в реальном Telegram на iOS/Android после deployment.
